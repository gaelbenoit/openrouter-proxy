- [Key persistence implementation](src/keyManager.ts) — Implemented persistent storage for API keys using keys.json file with proper loading/saving and description field
- [Key description for logging](src/keyManager.ts) — Added getKeyDescription() method to show meaningful key identifiers in logs (description or abbreviated format) and replaced all apiKey.slice(-4) usages
- [Test-safe key storage](src/keyManager.ts, tests/keyManager.test.ts) — Modified KeyManager to use KEYS_STORAGE_PATH environment variable to allow tests to run without interfering with real keys.json
- [Documentation](.env.example) — Added KEYS_STORAGE_PATH to .env.example to indicate how to override the keys storage path
- [Key rotation with cooldown](src/keyManager.ts, src/types.ts) — Added cooldownUntil to KeyInfo and updated markKeyRateLimited to set cooldown until end of day (23:59:59.999) without deactivating the key. getNextKey now filters out keys in cooldown. Non-rate-limit errors still contribute to failure threshold for deactivation.
- [Key reuse for cache efficiency](src/server.ts, src/keyManager.ts) — Modified server to reuse the same API key across requests until it fails, reducing OpenRouter cache misses. Added currentApiKey tracking and isKeyUsable() method.
- [Daily usage tracking](src/keyManager.ts, src/types.ts) — Added dayCount to KeyInfo to track successful requests per day. dayCount is incremented on successful requests and reset to 0 when the key is used on a new day (based on lastUsed date). Provides getDayCount() method to retrieve current day's usage.
- [Daily failure count reset](src/keyManager.ts, src/config.ts) — Updated failureCount to reset daily like dayCount. Increased default KEY_FAILURE_THRESHOLD from 3 to 10 in config.ts. Added isSameDay helper and resetDailyCountersIfNewDay logic to markKeySuccessful and markKeyFailed. Excluded 400 errors from failure counting due to OpenRouter bug.
